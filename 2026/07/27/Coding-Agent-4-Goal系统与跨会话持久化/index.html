入门 Coding Agent（四）：当 Agent 醒来时——Goal 系统与跨会话持久化

发表于 2026-07-27 更新于 2026-08-20 分类于 Coding Agent 原理 本文字数： 1.6k 阅读时长 ≈ 6 分钟
解释 Goal 系统如何保存未完成任务、跨越对话生命周期，并让 Coding Agent 恢复长期工作。

本篇不再基于 mini-swe-agent，而是以 Codex（桌面版 Coding Agent）的 Goal 系统为蓝本讲解。所有机制均来自对实际运行时的逆向观察和工具接口的交互验证。

一、前情回顾：一个循环里的 Agent

前三篇我们构建了一个完整的 Agent 心智模型：

  1. 核心循环：Agent = 推理 → 执行 → 观察 → 循环
  2. 三体架构：Agent（决策者）→ Model（翻译官）→ Environment（执行者）
  3. 保险丝设计：步数上限、金额上限、时间上限等硬边界

但这个模型有一个隐含假设：Agent 的生命周期等于一次对话的生命周期。你发起一个任务，它在循环里跑，跑完结束，对话关闭。

如果任务在一步之内就能完成，这个模型没问题。但如果任务是”重构一个大型模块”或者”实现一个完整的博客系统”呢？

二、被遗忘的问题：对话会结束

现实中，Coding Agent 的每次对话都有天然的限制：

  • Token 预算：每次对话有成本上限，用完了得停
  • 上下文窗口：当历史越来越长，最终会撑满模型的最大上下文
  • 自动压缩：系统会把历史压缩成摘要来节省空间，但压缩会丢失细节

当这些限制被触发时，对话结束。下一轮你重新打开 Agent，它面对的是一个空白状态。

这里出现了一个基本矛盾：

Agent 的工作可以跨多轮对话，但 Agent 的”记忆”只在单轮对话内有效。

需要有一种机制，让 Agent 能”记住”它在一个长任务中做到哪了，并在下一轮自动续上。

三、Goal 系统：Agent 与 Runtime 的契约

Goal 系统就是解决这个问题的方案。它不是 Agent 内部的循环机制，而是 Agent 和运行时（Runtime）之间的一份持久化契约。

五、两个终态：Complete 与 Blocked

update_goal 只接收两个状态值：

Complete（完成）

Agent 根据 objective 判断任务是否达成。比如目标是”重构模块 X 并确保测试全部通过”，Agent 改完代码、跑完测试、全部绿了，它就调用 update_goal(complete)。

这里没有外部验证机制——Agent 用自己的判断来决定是否完成。如果它误判了（测试写漏了、边界没覆盖），那 goal 已经结束，不会自动续期。你需要手动重新开一个 goal，或者直接告诉 Agent 继续改。

这个设计是故意的：如果 complete 加了自动验证，Agent 和验证者可能是同一个模型，判断逻辑打架会导致死循环。

Blocked（受阻）

当 Agent 在任务中遇到无法自行解决的障碍（需要你提供 API key、某个依赖不兼容、需要决策方向），它会调用 update_goal(blocked)。

Blocked 的效果是：Runtime 停止自动续期，等待你介入。 你解决了问题后，告诉 Agent”继续”，Agent 重新开始工作。

注意这个不对称设计：

状态 Runtime 行为 控制权
complete 结束，不续期 交给 Agent 判断
blocked 暂停续期，等用户 交给你

Blocked 会暂停循环，因为控制权需要转到你手里。Complete 不做二次验证，因为验证者和执行者是同一个模型，循环验证会产生死循环风险。

六、Token Budget：持久工作的燃料

token_budget 不仅是成本控制，更是”跨轮次工作”的保障。

没有 Goal 系统时：Agent 只有”这一轮对话”的生命周期。

有 Goal 系统时：Agent 可以创建一个 token_budget=150000 的目标，本轮花了 60000，Runtime 看到还没用完，自动续下一轮继续花。下一轮 Agent 醒来，get_goal() 返回 tokens_used=60000, token_budget=150000，知道还剩 90000 的预算。

这就是”持续不断工作”的燃料保障。

八、小结

Goal 系统的核心哲学是：Agent 做判断，Runtime 做保障。 Agent 决定目标是否完成、是否受阻；Runtime 根据目标状态决定是否续期、是否暂停。

四篇下来，我们已经构建了一个完整的 Coding Agent 心智模型：从单次对话内的循环，到跨会话的持久化；从决策逻辑，到安全边界。这些加在一起，就是一个生产级 Coding Agent 的完整蓝图。
