第一层：标准化的错误分类

第二层：超时控制

任何一步都不能无限等：

LLM 调用设 15 秒超时，工具调用设 1.2 秒超时。超时错误被标记为 retryable: true，自动进入重试流程。

第三层：退避重试 + 抖动

简单的重试不够——如果所有失败请求同时重试，雪崩效应会打垮下游服务。

退避策略：

指数增长 + 随机抖动 = 既等得起，又不会挤在一起。

第四层：主备切换

工具也可以有”备用”：

主服务可能返回最新但偶尔超时的数据，备服务可能略旧但永远可用。这就是微服务里断路器模式在 Agent 层的应用。

第五层：降级模式

最关键的防御——不是 LLM 挂了整个系统就挂了。

降级模式用纯代码（正则提取 user id → 调工具 → 拼结果）继续服务。用户可能只注意到”回复简单了点”，而不是看到报错页面。
