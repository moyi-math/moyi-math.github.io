Hello算法 学习笔记 · 7.1 二叉树：一对多的层次结构

发表于 2026-07-30 分类于 Hello算法学习笔记 本文字数： 2k 阅读时长 ≈ 7 分钟
树是第一种非线性数据结构——一对多的层次关系。二叉树每个节点最多两个分支，是树结构的基础。本文从节点定义到四种遍历方式（BFS层序、DFS前/中/后序）逐层拆解，理解遍历的本质就是"待办清单"。

章节定位: 前几章学的都是线性结构（数组、链表、栈、队列、哈希表）——数据一对一排列。本章进入非线性结构的第一站：树（Tree）。树是一对多的层次关系，而二叉树（Binary Tree） 是最基础的树形结构。文件系统、编译器语法树、数据库索引，底层都是树。

摘要(Abstract)

TL;DR: 二叉树是每个节点最多有两个子节点的树形结构。节点散落在内存中，通过 left 和 right 指针连接。和链表相比，链表只有 next（一个方向），二叉树有 left 和 right（两个方向）。二叉树的遍历有四种方式：层序遍历（BFS，用队列）和前序/中序/后序遍历（DFS，用递归）。理解遍历的关键是理解”队列/栈是用来记住待办事项的”。

本文覆盖:

  • 为什么需要树: 从线性结构到一对多的层次关系
  • 二叉树的定义: TreeNode(val, left, right)——每个节点最多两个子节点
  • 树的术语: 根节点、叶子节点、子树、高度、深度
  • 特殊形态: 满二叉树、完全二叉树
  • 层序遍历 BFS: 用队列逐层从上到下遍历
  • 前序/中序/后序遍历 DFS: 递归深入，根节点的访问位置决定名称
  • 遍历的本质: 队列和栈都是”待办清单”，只是顺序不同
  • 面试高频题: 3 道覆盖二叉树核心知识的面试题

适合读者: 第一次接触树形结构的初学者；对 BFS/DFS 遍历为什么要用队列/递归感到困惑的学习者。

二、二叉树的定义

二叉树是每个节点最多有两个分支的树。

每个节点就三个东西：自己的值、左孩子的指针、右孩子的指针。

和链表的关系： 链表节点只有 next，二叉树节点有 left 和 right。链表是”单行道”，二叉树是”双岔路”。

三、树的术语

术语 含义
根节点 树的最顶层节点，没有父节点
父节点 / 子节点 相连的两个节点，上层是父，下层是子
叶子节点 没有子节点的节点
子树 任何一个节点及其所有后代构成一棵子树
高度 从根到最远叶子节点的边数
深度 从根到该节点的边数

四、二叉树的特殊形态

  • 满二叉树：所有层的节点数都达到最大值（每层 2^level 个）
  • 完全二叉树：除了最后一层，其他层都满；最后一层的节点靠左排列

完全二叉树后面会用到——堆（Heap）就是用数组存完全二叉树。

五、层序遍历（BFS）——逐层从上到下

层序遍历的目标：按层从上到下，每层从左到右遍历所有节点。

为什么 BFS 要用队列？

完整手工追踪一次：

队列 = “待办清单”。

  • 入队 = 把”以后要访问的节点”记在清单上
  • 出队 = 从清单上取一个来访问

队列的先进先出特性保证了：先发现的节点先被访问，同一层从左到右，一层完了再下一层。

六、DFS 三种遍历——递归深入

DFS 用递归（或显式栈）实现。”一条路走到底，回头再走另一条”。

前序遍历：根 → 左 → 右

中序遍历：左 → 根 → 右

后序遍历：左 → 右 → 根

遍历方法对比

遍历方式 数据结构 顺序 用途
层序 BFS 队列 逐层从上到下 最短路径、层级分析
前序 DFS 递归/栈 根→左→右 复制树
中序 DFS 递归/栈 左→根→右 BST 升序输出
后序 DFS 递归/栈 左→右→根 删除树

BFS 用队列，DFS 用递归/栈，区别在哪里？

两者的本质都是**记住”还有哪些节点没访问”**：

  • BFS 用队列：先进先出 → 同一层先被发现的先访问 → 逐层展开
  • DFS 用递归/栈：后进先出 → 最后发现的先访问 → 一条路走到底

队列和栈只是”待办清单”的不同组织形式——顺序决定了遍历的顺序。

七、面试高频题

Q1: 二叉树和链表的区别是什么？

链表是线性结构（一对一），二叉树是树形结构（一对多）。链表节点只有一个 next 指针，二叉树节点有 left 和 right 两个指针。从代码上看，ListNode 和 TreeNode 只差一个指针字段，但表达能力完全不同——树可以表达层次、从属、包含关系。

Q2: BFS 为什么要用队列实现？用栈行不行？

BFS 要求先发现的节点先访问（先进先出），队列正好满足这个需求。如果用栈（后进先出），就会变成”后发现的先访问”，那不是 BFS，而是另一种 DFS。

Q3: 前序、中序、后序遍历各有什么实际用途？

  • 前序：复制一棵二叉树——先创建根节点，再递归创建左右子树
  • 中序：二叉搜索树的中序遍历结果是有序的（升序排列）
  • 后序：删除一棵二叉树——必须先删除子节点，再删除根节点

下一节预告: 普通二叉树的查找需要遍历整棵树——O(n)。二叉搜索树（BST） 加了一条规则（左 < 根 < 右），就让查找变成了 O(log n)。它是二分查找的树形实现。
